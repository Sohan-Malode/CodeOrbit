# CodeOrbit

### Turn Code into Clarity

CodeOrbit is a repository analysis tool that transforms source code into an interactive view of a project's structure, dependencies, and architecture.

It provides an easy way to explore how files and modules within a repository relate to each other without manually tracing the entire codebase.

---

## Features

- 📦 Analyze repositories from ZIP files
- 🔗 Analyze public GitHub repositories
- 🧪 Explore the included sample repository
- 🏗️ Interactive architecture graph
- 🔀 Dependency visualization
- 📊 Project statistics and insights
- 🌐 Mermaid diagram generation
- 📁 File Explorer
- 🔎 Source code preview
- 🤖 AI-powered file explanations
- 📤 JSON analysis export
- 🌙 Dark and light themes
- 💻 Supported language detection

---

## How It Works

CodeOrbit analyzes the source code of a repository and extracts information about its structure and relationships.

The analysis includes:

1. Repository files
2. Modules and source files
3. Import and dependency relationships
4. Project structure
5. Detected technologies
6. Architecture relationships
7. Project-level insights

The extracted information is then presented through CodeOrbit's interactive interface.
